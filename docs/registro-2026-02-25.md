## Correções técnicas importantes
- Erro de build no middleware (Next Edge + Prisma wasm):
  - removida dependência de import de `auth` que puxava Prisma em Edge.
  - middleware passou a usar token JWT diretamente.
- Erro ao salvar configurações:
  - ajuste no update/upsert para relação de usuário (`updatedByUser`) sem conflito de FK.
- Falha de envio/recebimento Evolution por host incorreto:
  - quando app roda no host e Evolution no Docker, corrigido fallback/resolução (`evolution-api` -> `localhost` no envio).
  - para webhook de entrada, padronização para `host.docker.internal` quando necessário.
- Falha de sincronização WhatsApp (`fetch failed`):
  - tratada com fallback de base URL e mensagens de erro melhores.

## Fluxo do bot (UX)
- Menus interativos: quando habilitados, as opções numéricas passaram a ser renderizadas como menu/lista interativa nos pontos do fluxo que ainda estavam texto puro.
- Fallback numérico mantido: usuário ainda pode digitar número manualmente.

## Novo fluxo de convênio não encontrado
Implementado no cadastro inicial:
1. Usuário informa que possui convênio.
2. Bot mostra lista de planos + opção `Meu plano não está na lista`.
3. Ao escolher essa opção, abre submenu:
   - `Seguir como particular`
   - `Validar convênio com atendente`
   - `Voltar para lista de planos`
4. Comportamentos:
   - `Seguir como particular`: conclui cadastro como particular.
   - `Validar convênio com atendente`: encerra no handoff humano com orientação para enviar dados do plano.
   - `Voltar`: retorna para lista de convênios.
