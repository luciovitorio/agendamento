Guia do Menu de Configuracao do Bot WhatsApp

Este documento explica cada campo da aba Bot WhatsApp em /admin/settings?tab=bot e mostra como configurar para funcionar hoje sem n8n, deixando n8n pronto para uso opcional no futuro.

1) Configuracao minima para funcionar (sem n8n)

  1. Abra a aba Bot WhatsApp.
  2. Preencha: numero da clinica, URL da Evolution, nome da instancia e token da Evolution.
  3. Salve as configuracoes.
  4. Clique em Sincronizar WhatsApp e escaneie o QR Code.
  5. Confirme status WhatsApp conectado.
  6. Na secao Destino do webhook, selecione Sistema (sem n8n), informe a URL base do seu sistema e clique em Aplicar webhook no Evolution. O destino final sera /api/evolution/webhook.
  7. Se quiser proteger entrada, preencha Token do webhook (entrada) e envie o mesmo token no header: Authorization: Bearer SEU_TOKEN (ou x-evolution-webhook-token).
Se a instancia estiver conectada, os campos de numero/URL/instancia/token da Evolution ficam bloqueados. Para alterar, use Desconectar instancia ou Excluir instancia.

2) Integracao WhatsApp

Campo / Acao Para que serve Como preencher
Numero WhatsApp da clinica Numero oficial usado no atendimento. Formato BR com DDD + numero (10 ou 11 digitos).
URL da Evolution API Endereco base da API Evolution. Ex.: http://localhost:8080 ou URL publica.
Nome da instancia Identificador da sessao WhatsApp na Evolution. Use nome unico e estavel por clinica.
Token da Evolution API Autenticacao para chamadas de envio/controle da instancia. Token gerado na Evolution.
Token do webhook (entrada) Protege o endpoint /api/evolution/webhook. Opcional, mas recomendado em producao.
Sincronizar WhatsApp Consulta/cria instancia e retorna QR Code quando necessario. Use depois de salvar os campos da Evolution.
Desconectar instancia Despareia WhatsApp sem apagar configuracao. Use para trocar conta ou editar integracao bloqueada.
Excluir instancia Remove instancia na Evolution. Use com cuidado; exige nova sincronizacao completa.

3) Integracao n8n (opcional por cliente)

Hoje voce pode operar sem n8n. Esta secao fica pronta para clientes que precisem integrar agenda externa/ERP/Google Calendar.

Campo / Acao Uso Exemplo
Encaminhar para Escolhe o destino do webhook da Evolution: sistema ou n8n. Sistema (sem n8n) para demo/trial.
URL base do sistema Base usada quando o destino for o proprio sistema. https://seu-dominio.com ou http://localhost:3000.
Modo de webhook (n8n) production usa /webhook; test usa /webhook-test. Padrao: production.
URL base do n8n Endereco do n8n para montar URL final de webhook. http://n8n:5678 (docker) ou URL publica.
Path do webhook no n8n Slug do endpoint do workflow no n8n. evolution.
Aplicar webhook no Evolution Configura a Evolution para enviar evento ao destino selecionado. Use sempre apos trocar destino/campos.
Verificar webhook atual Le o webhook ativo da instancia na Evolution. Valida se URL/eventos estao corretos.

4) Regras operacionais

  • Bot habilitado: liga/desliga respostas automaticas.
  • Cancelar automaticamente: permite cancelamento direto no bot.
  • Remarcar automaticamente: controla resposta automatica para remarcacao.
  • Menus interativos: usa listas/botoes nativos do WhatsApp.

5) Comportamento do bot

Reconhecimento e agenda

  • Saudacoes reconhecidas: palavras separadas por virgula.
  • Dias para buscar disponibilidade: janela de busca no calendario.
  • Maximo de dias mostrados: quantos dias sugerir para o paciente.
  • Horarios no resumo por dia: limite de horarios exibidos por linha.
  • Limite de agendamentos listados: tamanho da lista "Meus agendamentos".

Digitacao simulada

  • Delay de digitacao (ms): espera antes de enviar resposta.
  • Presenca de digitacao: composing, recording ou paused.

6) Menus interativos

Campo Impacto na conversa Dica pratica
Titulo do menu interativo Titulo principal da lista enviada no WhatsApp. Curto e claro, ex.: "Opcoes".
Texto do botao do menu Texto do botao que abre a lista. Ex.: "Ver opcoes".
Titulo da secao Cabecalho da lista de itens. Ex.: "Selecione uma opcao".
Rotulo do botao voltar Texto do item de voltar (id 0). Ex.: "Voltar".
Descricao do botao voltar Descricao adicional do item "Voltar". Ex.: "Voltar ao menu".

7) Mensagens do bot

Campos editaveis no painel:

  • Boas-vindas
  • Primeiro contato
  • Fallback
  • Horario de atendimento
  • Confirmacao
  • Cancelamento
  • Remarcacao
  • Encaminhamento humano

Todas as mensagens aceitam texto livre (ate 1000 caracteres cada).

8) Checklist de validacao

  1. Bot habilitado = ligado.
  2. Evolution conectada e com instancia aberta.
  3. Webhook apontando para o destino correto (sistema ou n8n).
  4. Token de webhook configurado de forma consistente (se ativado).
  5. Enviar mensagem real no WhatsApp e validar resposta do bot.
  6. Testar fluxo: agendar, listar, cancelar e fallback.

9) Estrategia recomendada para seu cenario

  • Padrao para demo e trial: Evolution + seu sistema (sem n8n no caminho principal).
  • Cliente com sistema externo: habilitar modo n8n por cliente e manter mesma experiencia de conversa.
  • Evitar: duas logicas diferentes de bot em paralelo.
